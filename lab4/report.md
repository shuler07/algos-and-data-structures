## Лабораторная работа №4

##### Цель работы:
Изучение динамических самобалансирующихся структур данных на примере **AVL-дерева** (вариант 1). Реализация основных операций: добавление узла с балансировкой, удаление узла с балансировкой, поиск значения по ключу и печать дерева. Проведение анализа производительности с помощью Google Test и Google Benchmark.

##### Идея, метод, алгоритм решения задачи:
Программа реализует упорядоченное AVL-дерево для хранения уникальных строковых ключей (до 6 символов) и вещественных значений. Ключи упорядочиваются лексикографически. 
* **Балансировка**: Для каждого узла поддерживается условие, при котором разница высот его левого и правого поддеревьев не превышает единицы.
* **Операции**: При вставке и удалении выполняется рекурсивный пересчет высот и, при необходимости, один из четырех типов вращений (малое левое/правое или большое лево-правое/право-левое).
* **Интерфейс**: Реализована поддержка командного файла, где операции задаются номерами: 1 (добавление), 2 (удаление), 3 (поиск), 4 (печать).

##### Сценарий выполнения работы:
1. Разработка структур данных для узла дерева (ключ, значение, высота, указатели на потомков).
2. Реализация функций вращения и балансировки для поддержания свойств AVL-дерева.
3. Реализация парсера входных команд из текстового файла в формате `<номер операции> [<ключ>] [<значение>]`.
4. Организация вывода результатов выполнения команд в файл в формате: сначала команда, затем её результат.
5. Покрытие кода модульными тестами (Google Test), включая проверку дерева объемом более 20 узлов.
6. Проведение замеров времени выполнения операций через Google Benchmark.
