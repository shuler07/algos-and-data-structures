## Лабораторная работа №5

##### Цель работы:
Изучение алгоритмов на графах и методов их представления. Реализация алгоритма поиска минимального остовного дерева (MST) методом **Краскала** (вариант 4) с использованием системы непересекающихся множеств (**DSU**). Проведение структурного тестирования и анализа производительности реализации.

##### Идея, метод, алгоритм решения задачи:
Программа работает с неориентированным взвешенным графом, представленным в виде **матрицы смежности** и **списка ребер**.
*   **Система непересекающихся множеств (DSU)**: Применяется для эффективной проверки принадлежности вершин разным компонентам связности, что позволяет избежать образования циклов при добавлении ребер. Используется оптимизация «сжатия путей» (path compression).
*   **Алгоритм Краскала**: 
    1. Все ребра исходного графа упорядочиваются по возрастанию веса. В данной реализации это достигается путем вставки в сортированный двусвязный список.
    2. Ребра последовательно извлекаются из списка.
    3. С помощью DSU проверяется, создаст ли текущее ребро цикл. Если вершины ребра находятся в разных множествах, ребро добавляется в MST, а множества объединяются.
*   **Интерфейс**: Реализовано текстовое меню для управления графом: создание, добавление связей, визуализация матрицы и запуск расчета MST.

##### Сценарий выполнения работы:
1. Проектирование структур данных для графа (матрица смежности и массив ребер) и узлов вспомогательного списка.
2. Реализация модуля DSU: функции `dsuCreate`, `dsuFind` (с рекурсивным сокращением пути) и `dsuUnion`.
3. Разработка логики вставки ребер в список с автоматической сортировкой по весу для подготовки данных к алгоритму Краскала.
4. Реализация основного алгоритма `graphKruskal`, формирующего новый объект графа, содержащий минимальный остов.
5. Покрытие кода модульными тестами (Google Test), включая краевые случаи: треугольный граф, проверка на циклы и работа с несвязным графом (лес деревьев).
6. Замер временных характеристик алгоритма при разном количестве вершин и плотности ребер через Google Benchmark.

### Вывод
В ходе выполнения работы был успешно реализован алгоритм Краскала для поиска минимального остовного дерева с использованием системы непересекающихся множеств (DSU).
