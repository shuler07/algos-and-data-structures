## Лабораторная работа №6

##### Вариант:
Рекурсивный обход указанного каталога и замена всех разделитеоей пути \ на / в файлах с именем Makefile*

##### Структура репозитория:
<pre>
├── lab6/
│   ├── test-dir/         # Директория для тестирования работы скрипта
│   ├── script.sh         # Скрипт с выполнением указанного варианта
│   └── report.md         # Данный отчет
</pre>

##### Реализация:

---

`shopt -s globstar`
Позволяет использовать ** для рекурсивного обхода указанной директории

---

```
if [[ "$1" ]]; then
    dir="$1"
else
    dir="."
fi
```
Считываем из первого аргумента директории, если указана. Если не указана - по умолчанию работаем в текущей директории

---

```
if [[ ! -d "$dir" ]]; then
    echo "Directory not found"
    exit 1
fi
```
Проверяем, существует ли указанная директория. Если нет - пишем предупреждение и выходим из скрипта

---

`cd "$dir"`
Переходим в указанную директорию

---

```
for file in **/Makefile*; do
    ...
done
```
Ищем в указанной директории файлы и папки, название которых начинается на Makefile.

---

```
    if [[ -f "$file" ]]; then
        ...
    fi
```
Для каждого найденного элемента проверяем, что это файл.

---

```
        content=$(< "$file")
```
Если это файл - считываем его содержимое в content

---

```
        echo "${content//\\//}" > "$file"
```
Заменяем в content все \ на / и стримим обратно в file
